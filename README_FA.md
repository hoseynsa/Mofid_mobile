# پروژه پایه اندروید مفید

این خروجی یک **پروژه منبع Android/Kotlin** است، نه APK آماده نصب.

## وضعیت فعلی
- رابط فارسی ساده
- دو زمان‌بند مستقل Probe و سفارش اصلی
- مقدار اولیه هر دو نرخ: ۲۰۰ درخواست/ثانیه (فاصله اسمی ۵ میلی‌ثانیه)
- توقف اضطراری
- در این نسخه هیچ ارتباط شبکه‌ای و هیچ سفارش واقعی انجام نمی‌شود؛ فقط زمان‌بندی محلی و شمارنده آزمایش می‌شود.

## چرا هنوز سفارش واقعی وصل نیست؟
فایل Python v12.10 از Playwright/Firefox، ورود OAuth/PKCE، کوکی و توکن مرورگر، aiohttp و رابط دسکتاپ استفاده می‌کند. این اجزا را نمی‌توان با تبدیل مستقیم به APK منتقل کرد و باید در Kotlin بازنویسی و جداگانه اعتبارسنجی شوند.
نکته مهم: تابع Probe نسخه پایتون درخواست POST به endpoint سفارش می‌فرستد؛ پس Probe واقعی ممکن است سفارش واقعی ثبت کند و «فقط تست» یا read-only نیست.

## باز کردن پروژه
1. پوشه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync انجام شود.
3. روی گوشی با USB debugging یا شبیه‌ساز اجرا کنید.

برای ساخت APK باید Android SDK و Android Studio/Gradle در دسترس باشند. این محیط APK را کامپایل نکرده است.
## محدودیت زمان‌بندی
۲۰۰ درخواست/ثانیه فقط نرخ هدف زمان‌بند است. اندروید، زمان‌بندی نخ‌ها، شبکه و سرور کارگزاری تضمین ۵ms نمی‌دهند. اجرای دو مسیر هم‌زمان می‌تواند به نرخ مجموع ۴۰۰ درخواست/ثانیه برسد.
قبل از اتصال adapter واقعی باید API مجاز/مستند کارگزاری، احراز هویت امن با Android Keystore، محدودیت نرخ و کنترل سفارش‌های تکراری بررسی شود.
